# 🏨 Stayo – Hotel Booking Platform

Stayo is a full-stack hotel booking platform built using the MERN stack. The application allows users to browse hotel listings, view property details, and manage bookings through a responsive and user-friendly interface.

## 🚀 Features

* User Authentication & Authorization
* Browse Hotel Listings
* Property Details Page
* Hotel Booking Management
* Responsive Design
* RESTful API Integration
* Secure Backend Architecture

## 🛠️ Tech Stack

### Frontend

* HTML5
* CSS3
* Bootstrap

### Backend

* Node.js
* Express.js

### Database

* MongoDB
* Mongoose

* Git

## ⚙️ Installation

```bash
git clone <repository-url>
cd stayo
```

Install dependencies:

```bash
npm install
```

Start frontend:

```bash
npm run dev
```

Start backend:

```bash
npm start
```
